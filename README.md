## Seminar — An introduction to Differential Evolution

Seminar (slides + a 4-to-6-page paper in the SBC template) on **Differential Evolution (DE)**,
a population-based meta-heuristic for continuous optimization proposed by Storn and Price (1995/1997).

- **Content:** history and state of the art, applications, the classic **DE/rand/1/bin** algorithm
  (differential mutation, binomial crossover and greedy selection), pseudocode, variants
  (`best/1`, `rand/1`, `best/2`, `current-to-best/1`), the role of the parameters $NP$, $F$ and $CR$, and the
  balance between diversification and intensification.
- **Application example:** minimizing the **2D Rastrigin function** (121 local minima in the
  domain $[-5.12;\ 5.12]^2$) with the [pymoo](https://pymoo.org) library, configured to
  faithfully reproduce the original DE ($NP=20$, $F=0.5$, $CR=0.9$, without the extra polynomial mutation).
- **Result:** DE finds the global minimum $f(0,0)=0$ (error $\approx 10^{-15}$ in 100 generations,
  $f<10^{-6}$ from generation 61 on). The notebook also produces a step-by-step numerical example of
  one generation, the population's evolution over the function landscape, convergence curves and an
  animation (GIF) used in the slides.

## T1 — The *Splitwise* problem: constructive heuristics and local search

Given a group of people with net balances (summing to zero), the *Splitwise* problem consists of
settling every debt with the **smallest possible number of transactions**.

- **Modeling:** the optimal value is $f^* = n' - k_{\max}$, where $k_{\max}$ is the largest number of
  zero-sum groups the people can be partitioned into. The solution is represented as a
  **permutation** decoded as a chain of transfers — every permutation is feasible and every partition
  is representable.
- **Constructive algorithms:**
  - **ACG** (greedy) — picks the candidate that leaves the group's residual closest to zero;
  - **ACR** (randomized) — same greedy function with a restricted candidate list (RCL, $k=3$).
- **Local search:** **swap** neighborhood with **incremental** evaluation in
  $O(\log n')$ per neighbor, using the **first-improvement (BL_FI)** and
  **best-improvement (BL_BI)** strategies, starting from ACG and ACR.
- **Experiments:** 32 instances (from 20 to 1500 people). Local search reduces the number of
  transactions by 6.5% on average starting from ACG, reaching ~27% on instances with large groups of
  small values. Full results in
  [`T1/resultados/tabela_resultados.csv`](T1/resultados/tabela_resultados.csv) and in the plot
  [`grafico_construtivo_vs_bl.png`](T1/resultados/grafico_construtivo_vs_bl.png).

### How to run

Dependencies: `numpy`, `pandas`, `matplotlib`. Run the notebook from the `T1/` folder
(it reads `instancias/` and writes to `resultados/`):

```bash
cd T1
pip install numpy pandas matplotlib jupyter

```
