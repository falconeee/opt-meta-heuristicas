from pymoo.algorithms.soo.nonconvex.de import DE

from pymoo.optimize import minimize

 

algoritmo = DE(pop_size=20,

variant="DE/rand/1/bin",

F=0.5, CR=0.9,

jitter=False,  # F constante

prob_mut=0.0)  # sem mutação extra

res = minimize(Rastrigin(), algoritmo,

("n_gen", 101), seed=42,

save_history=True)

Usamos a biblioteca pymoo, que tem uma implementação dedicada da ED. Comparamos com outras opções: o pygmo porta o código original de Storn, mas não tem pacote para Mac ARM, e o mealpy não usa o j_rand no cruzamento. Atenção aos padrões do pymoo: a variante padrão é DE/best/1/bin, o CR padrão é 0,2, e a biblioteca aplica uma mutação polinomial extra depois do cruzamento, que não existe no algoritmo original. Por isso esses três argumentos são definidos explicitamente. O ambiente foi montado com o uv.
