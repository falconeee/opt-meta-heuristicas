Mutação: somar uma diferença ponderada

r₁, r₂ e r₃ são índices sorteados, distintos entre si e de i — por isso NP ≥ 4.

F é o fator de escala: controla o tamanho do passo (tipicamente entre 0,4 e 1).

Direção e tamanho do passo vêm da própria população, não de uma distribuição fixa.

Este é o coração do método. Para cada alvo, sorteamos três outros vetores. A diferença entre dois deles, multiplicada por F, é somada ao terceiro, o vetor-base. No desenho, a seta azul é a diferença entre x r2 e x r3; a laranja é a mesma diferença multiplicada por F = 0,5, aplicada a partir de x r1. O ponto importante: a ED não tem uma distribuição de mutação fixa, como as estratégias evolutivas. O passo vem das diferenças entre os próprios indivíduos, então se ajusta sozinho à dispersão da população.
